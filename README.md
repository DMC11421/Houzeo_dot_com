# Houzeo Real Estate UI Clone

This is a **static real estate listing website** inspired by Houzeo, built using **plain HTML, CSS, and JavaScript** and deployed on **Vercel**.

## 📦 Deployment (Vercel)

This project is deployed as a **static site**.

### Deployment requirements:
- `index.html` must be in the root directory
- Assets served using absolute paths (`/assets/...`)
- No build step required

Vercel automatically detects and deploys the project.

---

## 🧠 Notes

- Images are stored inside the `assets/` folder
- CSS and JS are loaded using absolute paths
- The project does not use any framework (React/Vite/Next.js)
